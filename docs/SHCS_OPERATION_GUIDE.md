# SHCS Pilot — 몰드와 크림 참고량 사용 설명서

이 문서는 현재 구현된 기능과 앞으로 필요한 통합을 구분한다.

## 몰드 등록과 선택

1. SETTINGS → PRODUCTS → MOULDS에서 몰드를 확인한다.
2. + ADD MOULD에서 직접 내부 치수를 입력하거나 참고 규격을 불러온다.
3. 원형은 지름, 정사각/직사각은 가로·세로, 높이는 도구 자체 높이를 입력한다. 화면은 cm, 저장은 mm다.
4. 기준 반죽량은 해당 Formula에서 확인한 경우에만 g으로 입력한다. 높이·부피만으로 추정하지 않는다.
5. INVENTORY → COMPONENT에서 몰드를 선택하면 저장된 숫자 치수가 cm로 채워진다. 구운 시트·자투리는 실제 크기로 수정한다.

이름·SHAPE/SIZE 메모에 적힌 숫자는 자동으로 실제 치수로 확정하지 않는다. 누락 치수는 안내와 빈칸으로 표시하며, 이전 선택의 치수를 남겨두지 않는다. 기존 재고를 열었다 닫는 것만으로 DB 치수가 바뀌지는 않는다.

## 높이 10cm·바닥분리형 참고 몰드

명목 크기이며 보유 도구의 실측값은 아니다. 중앙 기둥이나 테이퍼를 제외하지 않은 외곽 바닥 면적이다. 기둥 지름을 모르는 상태에서 실제 반죽 면적·부피로 사용하지 않는다. 면적은 치수에서 매번 계산하므로 별도 값이 어긋나지 않는다.

| 크기 | 가로×세로×높이(cm) | 원형 외곽 면적(cm²) | 정사각 외곽 면적(cm²) |
|---|---|---:|---:|
| 6인치 참고 | 15×15×10 | 176.71 | 225 |
| 8인치 참고 | 20×20×10 | 314.16 | 400 |
| 10인치 참고 | 25×25×10 | 490.87 | 625 |

원형은 가로·세로가 지름의 외곽 범위를 뜻한다. 원형 면적은 가로×세로가 아니라 π×(지름/2)²다. 재고 조각의 가로×세로를 사용한 면적 환산은 직사각 조각의 참고값이다. 원형 전체 시트는 몰드 개수를 직접 입력한다.

참고 출처: [Freee Foods — Cake Tin Sizes](https://www.freee-foods.co.uk/gluten-free-baking-tips/conversion-tables/cake-tin-sizes/).
6/8/10인치≈15/20/25cm는 일반적인 명목 대응이다. 높이 10cm와 바닥분리형은 사용자 지정 조건이다.
상품별 실제 내경·높이·테이퍼는 다르며, 여섯 크기에 동일한 실제 상품 규격을 확인했다는 의미는 아니다.
[MolalaCook의 분리형 시폰팬](https://molalacook.com/products/baking-chiffon-cake-mold)은 크기/중앙 기둥 옵션을 구분하는 상품 예시로만 확인했다.

기존 몰드 5개를 변경하지 않고 [참고] 표기가 붙은 신규 6개를 추가했다. 기존 레시피·오더·세션에는 새 몰드를 자동 연결하지 않았다.

## 크림 초기 목표

생크림·샹티 계열 원형, 시트 3장/샌딩 2층, 완성 높이 약 8–10cm, 기본 아이싱 기준이다. 과일·커드·큰 파이핑·작업 여유분은 별도다. g은 설탕 등을 포함한 완성 크림 기준이다.

| 크기 | 샌딩 1층 | 샌딩 합계 | 아이싱 | 합계 |
|---|---:|---:|---:|---:|
| 6인치 | 225g | 450g | 250g | 700g |
| 8인치 | 400g | 800g | 350g | 1,150g |
| 10인치 | 625g | 1,250g | 500g | 1,750g |

8인치 샌딩 800g은 사용자 지정 초기 목표다. 다른 사이즈의 샌딩은 면적 비율로 조정한 추정이다.
아이싱은 기존 별도 참고량을 유지했다. 업계 공통 표준이나 SHCS 실측 결과가 아니다.
무스크림·휘핑가나슈·버터크림에는 Formula별 검증 없이 공통 적용하지 않는다.

이 표는 SETTINGS → 사용 설명서에서도 볼 수 있다. 참고량을 표시할 뿐 기존 Cake Size의 cream_g나 제품의 quantity_g를 자동 수정하지 않는다.

## 작업 중 최소 측정

레시피 원료 투입량, 제조 후 사용 가능 산출량, 제품에 배정한 양, 다시 보관할 잔량은 서로 다르다.
Base Weight는 제조 목표 g 프리셋이다. 실제 산출량이나 특정 케이크에 들어간 크림 g과 동일하지 않다.

처음에는 이번 작업의 크림 하나만 고른다. Formula 버전·제조 배수·사용 가능 산출량·남은 재고를 우선 남긴다.
샌딩/아이싱을 나눠 재지 못한 날에는 합계만 남긴다. 누락을 0g이나 실측으로 저장하지 않는다.
현재는 생산 세션 NOTES 한 곳에 다음처럼 적는다.

- 제품/사이즈/개수:
- Component/Formula 버전/배수:
- 추가 또는 대체 재료:
- 사용 가능 산출량 g:
- 제품 배정량 g / 실측·추정·미측정:
- 배정량에 작업 손실 포함 여부:
- 보관한 잔량 g 또는 개수:
- 별도 폐기량 / 다음에 잴 값:

볼에서 줄어든 무게에는 도구 잔량·폐기가 포함될 수 있다. 케이크에 추가된 무게를 잴 경우 같은 보드·받침과 해당 크림만 비교한다.
이미 전체 제조량을 재고에 입고했다면 잔량을 다시 입고하지 않는다. 사용/폐기 출고로 잔량을 맞춘다.

배치 재료비 ÷ 사용 가능 산출량 = 사용 가능 g당 재료비다. 이 단가에 제조 손실을 다시 가산하지 않는다.
예: $12로 제조해 사용 가능 크림 900g을 얻고, 케이크 600g+조립 손실20g+재고280g이면 이번 제품 배정비는 약 $8.27, 남은 재고는 약 $3.73이다.

## 아직 통합되지 않은 부분

Cake Size/Product Size의 관리 화면 통합, 제품별 샌딩/아이싱 목표 저장, Formula 버전 고정 원가,
실측 수율, 배치별 재고, 원자적 입출고와 과거 원가 스냅샷은 별도 단계다.
현재 참고표가 이 기능들을 구현했다고 가정하지 않는다.
기존 중복 사이즈·이름과 치수 불일치·누락 연결은 자동 수정하지 않았다.
DB 마이그레이션·기존 데이터 수정은 정확한 영향 범위와 롤백안을 확인하고 승인받은 뒤 진행한다.

## 코드 반영과 배포

GitHub 연결 브랜치의 코드는 Lovable 편집기에 동기화된다. 실제 사이트는 사용자가 Lovable에서 Publish/Update한다.
DB에 추가된 참고 몰드는 이미 운영 데이터에 존재하며 코드 배포와 별개다.
기존 값 복구와 데이터 삭제는 사이트 재배포만으로 이루어지지 않는다.
